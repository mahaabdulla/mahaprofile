# 10. MOTION DESIGN SYSTEM

Motion is a central part of this project.

Study the interaction philosophy of WHOISJOA and use Hidden Heroes for selected storytelling patterns.

Implement a coherent motion system.

## Required Motion Patterns

### Typography Reveals

Large headings should reveal smoothly as they enter the viewport.

Use staggered line or word animation where appropriate.

Arabic text animation must preserve correct shaping.

### Scroll-Driven Transitions

Selected sections should respond to scroll progress.

Use controlled changes in:

- Position.
- Scale.
- Opacity.
- Masking or clipping.
- Visual layering.

### Project Hover Interactions

Create refined interactions for project previews.

Possible effects:

- Image movement.
- Controlled scaling.
- Revealing project metadata.
- Smooth visual transitions.

### Page Transitions

Provide elegant navigation transitions where technically appropriate.

### Micro-Interactions

Add subtle feedback for:

- Buttons.
- Navigation links.
- Interactive labels.
- Project links.
- Language switching.

## Motion Principles

- Smooth, not sluggish.
- Expressive, not distracting.
- Purposeful, not random.
- Consistent easing and duration.
- No unnecessary motion on every element.

Support `prefers-reduced-motion`.

Avoid scroll hijacking that harms usability.

Animations must not block reading, navigation, or accessibility.
